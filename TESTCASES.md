# TESTCASES.md
Тест-кейсы для проверки API микросервиса объявлений  
Base URL: `https://qa-internship.avito.com/api/1`

---

## 1. Создание объявления (POST /item)

### TC-01. Успешное создание объявления
**Шаги:**
1. Отправить POST запрос:
   ```json
   {
     "title": "Laptop",
     "description": "Good laptop",
     "price": 50000,
     "sellerId": 123456
   }
   ```
**Ожидаемый результат:**
- Статус 200  
- В ответе есть поле `id`  
- Данные совпадают с отправленными  

---

### TC-02. Создание без title
**Шаги:** отправить JSON без поля `title`  
**Ожидаемый результат:** статус 400  

---

### TC-03. Невалидный sellerId (меньше 111111)
**Шаги:** сделать запрос с sellerId < 111111  
**Ожидаемый результат:** статус 400  

---

### TC-04. Негативная цена
**Шаги:** price = -10  
**Ожидаемый результат:** статус 400  

---

## 2. Получение объявления по id (GET /item/{id})

### TC-05. Успешное получение
**Шаги:**
1. Создать объявление  
2. GET /item/{id}  
**Ожидаемый результат:** статус 200, данные корректные  

---

### TC-06. Несуществующее объявление
**Шаги:** GET /item/99999999  
**Ожидаемый результат:** статус 404  

---

## 3. Получение всех объявлений продавца (GET /seller/{sellerId})

### TC-07. У продавца есть объявления
**Шаги:**
1. Создать два объявления с одним sellerId  
2. GET /seller/{sellerId}  
**Ожидаемый результат:** статус 200, массив ≥ 2  

---

### TC-08. У продавца нет объявлений
**Шаги:** GET /seller/{валидный sellerId без объявлений}  
**Ожидаемый результат:** статус 200, пустой массив  

---

### TC-09. Невалидный sellerId
**Шаги:** sellerId < 111111  
**Ожидаемый результат:** статус 400  

---

## 4. Получение статистики (GET /stat/{itemId})

### TC-10. Успешное получение статистики
**Шаги:** GET /stat/{существующий itemId}  
**Ожидаемый результат:** статус 200, есть поля статистики  

---

### TC-11. Несуществующий itemId
**Шаги:** GET /stat/99999999  
**Ожидаемый результат:** статус 404
